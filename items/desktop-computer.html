Before you recycle it

  • Does it still work?
  • Would someone realistically buy or use it?
  • Is repair sensible?
  • Does it contain personal data?
  • Are you bringing one item or a large quantity?

This directory keeps those checks brief. The main job is still to route you to the right local place or program.
